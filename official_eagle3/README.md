# Official EAGLE-3 experiment (vLLM Speculators)

This directory adds a **real Speculators EAGLE-3** experiment without deleting the existing custom `train_eagle.py` experiment.

## What is different from the old code?

The old code defines its own `Eagle3(nn.Module)` and trains it with hard-label cross entropy, then uses a hand-written `verify()` loop.  That is useful as an EAGLE-style toy/ablation, but it is not a faithful vLLM Speculators EAGLE-3 reproduction.

The scripts here instead delegate the algorithm to `vllm-project/speculators`:

- official multi-layer EAGLE-3 speculator architecture
- target/verifier hidden-state extraction through vLLM
- target-logit distillation loss used by Speculators
- TTT (`--ttt-steps 3` by default)
- official checkpoint/config format
- actual vLLM `method=eagle3` speculative inference and verification

## Fair on-policy vs off-policy comparison

The two training sets use exactly the same SQuAD questions/prompts.

- **off-policy**: assistant response is the SQuAD gold answer
- **on-policy**: assistant response is generated by `./target_sft`

All EAGLE hyperparameters are held constant.  Both variants use offline hidden-state caching so the only intended experimental difference is the response trajectory.

## Prerequisites

You need a compatible vLLM + `vllm-project/speculators` environment.  Set:

```bash
export SPECULATORS_DIR=$HOME/speculators
```

The existing project should already contain:

```text
train.jsonl
eval.jsonl
target_sft/
```

If `target_sft/` does not exist, create it with the project's existing SFT script first.

## Train both variants

```bash
chmod +x official_eagle3/run_train_offline.sh
./official_eagle3/run_train_offline.sh
```

Useful overrides:

```bash
MAX_SAMPLES=256 EPOCHS=3 LR=1e-4 TTT_STEPS=3 \
SPECULATORS_DIR=$HOME/speculators \
./official_eagle3/run_train_offline.sh
```

Outputs:

```text
official_eagle3/ckpt_off/checkpoint_best
official_eagle3/ckpt_on/checkpoint_best
```

## Inference + SQuAD evaluation using actual vLLM EAGLE-3

```bash
python3 official_eagle3/benchmark_vllm.py
```

This compares:

```text
SFT target only
SFT target + EAGLE3 off-policy
SFT target + EAGLE3 on-policy
```

with the same target, prompts, greedy decoding and max output length.  It reports EM, F1, ms/question, throughput and a greedy lossless-output sanity check.

## Acceptance rate from a vLLM server

Serve a trained speculator directly (Speculators checkpoints contain the verifier reference):

```bash
vllm serve official_eagle3/ckpt_on/checkpoint_best --port 8000
```

Then:

```bash
python3 official_eagle3/eval_server.py \
  --url http://127.0.0.1:8000/v1 \
  --target-tokenizer ./target_sft
```

`eval_server.py` reads vLLM Prometheus speculative-decoding counters when the installed vLLM exposes them and calculates accepted/drafted token ratio.

## Important comparability note

Speculators `prepare_data.py` applies the target tokenizer's chat template to conversation data.  Therefore the new official EAGLE-3 experiment evaluates the target and both EAGLE variants with that same chat-template rendering.  Do **not** directly compare the absolute latency/EM numbers to old `benchmark_all.py`, which feeds raw prompt strings; compare methods within `benchmark_vllm.py`.
